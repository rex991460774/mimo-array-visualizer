1.1.0 新增两项测角评估功能：噪声下的测角精度，以及频段评估中把 DBF 字典固定在设计频率。可以直接从 1.0.x 升级，旧的项目、草稿和分享链接都能打开，原有评估结果不变。

## 新功能

### 噪声下测角精度（测角性能 → 加噪声）

原来的测角误差是无噪声条件下的系统偏差：字典和通道都理想时，任何布局的误差都是 0，没法用来比较布局好坏。新增的「加噪声（蒙特卡洛）」模式按单通道 SNR（视轴目标、距离-多普勒 FFT 之后、单快拍）在每个视场角度做 200 次蒙特卡洛，给出：

- **RMSE 与克拉美-罗界（CRB）**：理想字典下蒙特卡洛结果贴近 CRB，口径越大、CRB 越小。
- **异常值概率随 SNR 的变化**：峰值跳出主瓣（跳到旁瓣或栅瓣）的概率，SNR 从 −20 到 40 dB 扫描。
- **门限 SNR**：视场内所有角度异常值都不超过 1% 所需的最低 SNR。旁瓣高、竞争峰裕量小的布局门限更高。

导入的单元方向图会降低偏轴目标的 SNR；导入的通道幅相和自定义字典也会体现在结果中。无噪声模式加了说明，避免把"误差恒为 0"误读为布局没有差别。

### 频段评估：DBF 字典频率

「频段与对比」新增「DBF 字典频率」开关：

- **跟随工作频率**（默认，与 1.0 相同）：固件按实际中心频率生成导向矢量。
- **固定在设计频率**：整个频段只用一套导向表。偏离设计频率时 sinθ 的估计按 f/f₀ 缩放，例如字典 77 GHz、工作在 81 GHz 时，15° 的目标会测成 15.8°。

## 升级

- Docker：`git pull && docker compose up -d --build`（需要重建镜像）。
- wheel：`pip install` 下方附件的 wheel 地址，然后重启服务。
- 源码 / systemd：`git pull`，再运行 `scripts/setup_server.sh`，然后重启服务。

## 验证

- CI（Python 测试 + ruff、ESLint + 前端单元测试 + 构建、Playwright 端到端测试）全部通过。
- 后端 246 个测试，前端 230 个单元测试，5 个浏览器端到端用例。新增测试固定了蒙特卡洛结果与 CRB 的一致性（理想字典下比值 0.8–1.25）以及固定字典时 sinθ 的缩放关系。
